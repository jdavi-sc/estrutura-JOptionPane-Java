## 📄 Descrição

Este é um programa simples desenvolvido em Java que utiliza a biblioteca `JOptionPane` para criar uma interface gráfica de interação com o usuário. O objetivo principal é solicitar dois números ao usuário, realizar a soma entre eles e exibir o resultado de forma intuitiva.

Após exibir a soma, o programa pergunta ao usuário se deseja realizar uma nova operação. Caso a resposta seja **"sim"**, o processo se repete **(loop)**. Se a resposta for **"não"**, o programa é finalizado.
